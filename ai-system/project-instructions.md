# CORE WEBSITE PHILOSOPHY

## 1. PROJECT STRUCTURE & DEVELOPMENT

Keep the project lightweight and easy to iterate on during the initial development phase. Create a **multi‑page website** using only the following files during the initial development phase:

- **index.html** (Home)
- **about.html** (About the Clinic + Doctor Profile)
- **services.html** (List of treatments + service descriptions)
- **contact.html** (Phone, address, Google Maps placeholder, simple form)
- **style.css**
- **script.js**

Requirements:

- All pages must be fully linked to each other.
- Use **style.css** for all styling.
- Use **script.js** for all animations, interactions, and motion.
- Do NOT create any additional folders or files at this stage.
- Do NOT introduce frameworks, build tools, routing systems, components, unnecessary abstractions, or excessive project structure.
- Keep the project extremely lightweight and easy to iterate on.
- Focus on visual quality, spacing, typography, responsiveness, and premium interactions first.
- Reorganize the project into a professional folder structure.
- Prioritize clean readable code, lightweight performance, maintainability, and smooth responsiveness.
- Introduce additional structure, abstractions, frameworks, or project complexity only after the entire multi‑page site looks polished and finalized, and only when explicitly instructed.

## 2. DESIGN SYSTEM

Create a cohesive design system for the homepage.

Unify:

- typography hierarchy
- eyebrow styling
- spacing rhythm
- card language
- hover behavior
- button treatment
- border radius
- shadow softness
- animation timing

Ensure all sections feel art-directed as one premium healthcare brand rather than independently designed blocks.

## 6. MOTION SYSTEM

Create a cohesive motion system across the homepage.

Animations should feel:

- restrained
- elegant
- smooth
- editorial
- premium

Use consistent:

- easing
- duration
- hover behavior
- reveal timing
- scroll interactions

Avoid flashy or excessive motion. Favor restraint and refinement over visual complexity.

Every visual decision should feel intentional, calm, and cohesive. Use a restrained palette and strategic use of accent. Avoid excessive saturation.

Prioritize cohesion across the entire homepage over making individual sections independently impressive. 

## Major Considerations

- Establish strong visual hierarchy with one dominant headline per section, clear section titles, controlled emphasis, and meaningful text sizing differences.
- Ensure all imagery maintains consistent lighting, cohesive color grading, clean composition, and a polished editorial aesthetic.
- Treat the header and footer as major brand-defining design elements rather than standard navigation sections. They should feel intentionally designed for the specific business align with the emotional tone and visual personality of the brand.
- The website should feel highly polished in both desktop and mobile views. Mobile responsiveness should feel intentionally designed, not merely compressed from desktop layouts.
- The website should build trust immediately, reduce anxiety around treatments, explain procedures in a simple and reassuring way, emphasize patient comfort and care, make contacting or booking appointments effortless, naturally showcase positive patient experiences, and visually stand apart from typical local clinic websites.
- Use the reviews, business details, and attached references to shape the emotional tone and trust-building approach throughout the website.
- Use the locally available project assets and branding references inside the project folder, including clinic images, interiors, signage, logo files, brand colors, uniforms, marketing materials, existing website references (if available), and other real business assets. Use these assets to guide the color palette and palette hierarchy, emotional tone, typography personality, spacing mood, imagery treatment, visual identity, and overall atmosphere.
- The website should visually feel connected to the business’s real-world identity, interiors, branding, and patient experience.
- Prioritize authentic business imagery and real-world brand references wherever possible. Do NOT generate artificial people, fake clinic photography, generic AI lifestyle imagery, or unrealistic placeholder visuals.
- AI-generated visuals should be limited to subtle supporting elements where appropriate, such as icons, simple illustrations, abstract graphic accents, subtle decorative shapes, and lightweight UI graphics. These supporting graphics should remain restrained, premium, and visually cohesive with the overall brand direction.
- Ensure fast-loading optimized experience. Clear CTA hierarchy throughout the website. When in doubt, choose restraint over visual complexity.

## Strict No’s

- Avoid visual clutter, excessive UI trends, decorative overload, generic SaaS aesthetics, and unnecessarily busy compositions.
- Do not create visual inconsistency
- Do not introduce trendy SaaS aesthetics
- Do not overuse gradients
- Do not use excessive glassmorphism
